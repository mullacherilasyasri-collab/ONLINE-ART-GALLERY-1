# Online Art Gallery

## Project Description
Online Art Gallery is a web-based platform where users can explore and purchase different types of artwork.

## Categories
- Paintings
- Digital Art
- Photography
- Abstract Art

## Features
- User Login and Signup
- Artwork Gallery
- Category Filtering
- Search Artwork
- Add to Cart
- Remove from Cart
- Checkout
- Responsive Design

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

## Project Structure
- index.html – Main webpage
- style.css – Website styling
- script.js – JavaScript functionality
